# Dokumentasi Kegiatan Workshop (Day 1)

## 1. Rangkuman Materi yang Disampaikan
Workshop hari pertama membahas bagaimana menggabungkan kecerdasan buatan (*AI*) dalam proses pengembangan produk digital secara efisien, serta bagaimana mengelola perubahan kode tersebut menggunakan Git dan GitHub. Materi dibagi menjadi beberapa sesi utama:
* **Pengantar AI & Prompt Engineering:** Menjelaskan bahwa AI sangat bergantung pada instruksi (*prompt*) yang diberikan[cite: 7]. Prompt yang baik harus memiliki struktur yang spesifik agar menghasilkan kode atau keluaran yang akurat[cite: 5, 8].
* **Struktur Prompt yang Baik (R-T-C-F):**
  * *Role*: Menentukan peran AI[cite: 9].
  * *Task*: Menentukan tugas atau tujuan utama[cite: 9].
  * *Context*: Memberikan latar belakang dan batasan masalah[cite: 9].
  * *Format*: Menentukan bentuk output yang diinginkan[cite: 9].
* **Pengenalan Git & GitHub:** 
  * **Git**: Sistem pengontrol versi terdistribusi (*Distributed Version Control System*) yang berjalan secara lokal di komputer untuk melacak perubahan file[cite: 14, 16].
  * **GitHub**: Platform berbasis web untuk menyimpan repository secara online dan memfasilitasi kolaborasi tim[cite: 16].
* **Git Workflow & Essential Commands:** Memahami siklus kerja dari *Working Directory* $\rightarrow$ *Staging Area* $\rightarrow$ *Git Directory (Repository)* menggunakan perintah esensial seperti `git init`, `git add`, `git commit`, `git remote`, dan `git push`[cite: 15, 17, 18].

## 2. Poin-Poin Penting & Pengetahuan Baru
* **Pentingnya Konteks dalam Prompt:** Memberikan konteks yang jelas (misalnya target pengguna, batasan teknologi HTML/CSS/JS tanpa *library* eksternal yang rumit) membuat AI menghasilkan kode yang jauh lebih relevan dan siap pakai[cite: 8, 10].
* **Siklus Staging Area:** Pemahaman mendalam mengenai fungsi *Staging Area* sebagai tempat penampungan sementara sebelum perubahan file disimpan secara permanen ke dalam *Git Directory* melalui perintah `commit`[cite: 15].
* **Keamanan Akses via SSH:** Pembelajaran mengenai cara membuat dan mendaftarkan kunci SSH (*SSH Key* dengan algoritma `ed25519`) agar koneksi antara komputer lokal dan GitHub aman tanpa harus selalu memasukkan kata sandi[cite: 23, 25].
* **Langkah Praktis Pembuatan Proyek:** Panduan dari instalasi Git dan VS Code, inisialisasi repository lokal, pembuatan kode aplikasi *Student Task Planner* dengan bantuan AI, hingga mengunggahnya ke GitHub[cite: 19, 20, 28].

## 3. Pendapat Pribadi tentang Day 1 Proyek Workshop
> Day 1 workshop ini sangat membuka wawasan baru mengenai bagaimana teknologi AI dapat berkolaborasi secara produktif dengan developer atau desainer. Selama ini saya mungkin sering menggunakan AI secara sembarang, tetapi melalui materi *Prompt Engineering* (dengan struktur *Role, Task, Context, Format*), saya menyadari bahwa kualitas hasil dari AI sangat ditentukan oleh seberapa detail dan terstruktur instruksi yang kita berikan[cite: 9]. Selain itu, materi praktik Git dan GitHub memberikan fondasi yang sangat penting untuk mengelola kode secara profesional, rapi, dan terstruktur[cite: 1, 4].
